# Projet de Site Web d'Entreprise

Ce dépôt contient les fichiers pour un site web statique d'entreprise, développé dans le cadre d'une épreuve.

## Structure du projet:
- `index.html`: La page d'accueil principale.
- `css/`: Dossier pour les feuilles de style.
- `js/`: Dossier pour les scripts JavaScript.
- `images/`: Dossier pour les ressources images.

Plus de détails sur la stratégie de branchement et les étapes de développement seront ajoutés au fur et à mesure de l'avancement du projet.
